\section{Danh sách API tiêu biểu}

Phụ lục này trình bày một số API tiêu biểu được sử dụng trong hệ thống chatbot hỏi đáp học phần. Các API được xây dựng nhằm phục vụ các chức năng chính như xác thực người dùng, xử lý hội thoại và xử lý dữ liệu giọng nói.

\subsection{API xác thực người dùng}

API xác thực thuộc User Service, được sử dụng để kiểm tra thông tin đăng nhập và cấp JWT Token cho người dùng sau khi xác thực thành công.

\begin{table}[H]
    \centering
    \renewcommand{\arraystretch}{1.8}
    \begin{tabular}{|c|c|}
        \hline
        \textbf{Thuộc tính} & \textbf{Giá trị}                     \\
        \hline
        Service             & User Service                         \\
        \hline
        Method              & POST                                 \\
        \hline
        Endpoint            & /user-service/api/v1/login           \\
        \hline
        Mục đích            & Xác thực người dùng và cấp JWT Token \\
        \hline
    \end{tabular}
    \caption{API đăng nhập người dùng}

\end{table}


\textbf{Request:}

\begin{verbatim}
{
    "username": "example@gmail.com",
    "password": "password"
}
\end{verbatim}


\textbf{Response:}

\begin{verbatim}
{
    "data": {
        "token": "JWT_TOKEN"
    },
    "message": {
        "message": "Login success!",
        "status": 200
    }
}
\end{verbatim}
\clearpage

\subsection{API xử lý Text-to-Speech}
API Speech-to-Text thuộc Chat Service, có nhiệm vụ nhận dữ liệu là câu trả lời của bot và chuyển thành âm thanh phát cho người dùng.
\begin{table}[H]
    \centering
    \renewcommand{\arraystretch}{1.8}
    \begin{tabular}{|c|c|}
        \hline
        \textbf{Thuộc tính} & \textbf{Giá trị}                                      \\
        \hline
        Service             & Chat Service                                          \\
        \hline
        Method              & POST                                                  \\
        \hline
        Endpoint            & /chat-service/api/v1/chat-message/voice/\{messageId\} \\
        \hline
        Header              & Authorization: Bearer JWT Token                       \\
        \hline
        Mục đích            & Chuyển đổi dữ liệu âm thanh thành văn bản             \\
        \hline
    \end{tabular}
    \caption{API chuyển đổi văn bản thành giọng nói}

\end{table}


\textbf{Response mẫu:}
\begin{verbatim}
[
    {
        "type": "audio.chunk",
        "audio": "AUDIO_CHUNK_DATA_1"
    },
    {
        "type": "audio.chunk",
        "audio": "AUDIO_CHUNK_DATA_2"
    },
    {
        "type": "audio.chunk",
        "audio": "AUDIO_CHUNK_DATA_3"
    }
]
\end{verbatim}

\clearpage


\subsection{API Speech-To-Text}
Chat-Service cung cấp API tiếp nhận file âm thanh và thực hiện xử lý chuyển đổi giọng nói thành văn bản.
\begin{table}[H]
    \centering
    \renewcommand{\arraystretch}{1.8}
    \begin{tabular}{|c|c|}
        \hline
        \textbf{Thuộc tính} & \textbf{Giá trị}                    \\
        \hline
        Service             & Chat Service                        \\
        \hline
        Method              & POST                                \\
        \hline
        Endpoint            & /chat-service/api/v1/voice-to-text  \\
        \hline
        Input               & Multipart audio file                \\
        \hline
        Header              & Authorization: Bearer JWT Token     \\
        \hline
        Mục đích            & Nhận diện nội dung từ file âm thanh \\
        \hline
    \end{tabular}
    \caption{API Speech-To-Text}
\end{table}

\textbf{Request:}
\begin{verbatim}
audio_file = question.mp3
\end{verbatim}

\textbf{Response mẫu:}
\begin{verbatim}
{
    "text": "Xin chào, tìm hiểu tôi học phần lập trình mạng.",
    "logprobs": null,
    "usage": {
        "input_tokens": 34,
        "output_tokens": 15,
        "total_tokens": 49,
        "type": "tokens",
        "input_token_details": {
            "audio_tokens": 34,
            "text_tokens": 0
        }
    }
}
\end{verbatim}
\clearpage

API được sử dụng để tạo một phiên hội thoại mới khi người dùng bắt đầu tương tác với chatbot.

\begin{table}[H]
    \centering
    \renewcommand{\arraystretch}{1.7}
    \begin{tabular}{|c|c|}
        \hline
        \textbf{Thuộc tính} & \textbf{Giá trị}                          \\
        \hline
        Service             & Chat Session Service                      \\
        \hline
        Method              & POST                                      \\
        \hline
        Endpoint            & /chat-session-service/api/v1/init-session \\
        \hline
        Header              & Authorization: Bearer JWT Token           \\
        \hline
        Mục đích            & Tạo mới một phiên hội thoại               \\
        \hline
    \end{tabular}
    \caption{API khởi tạo phiên hội thoại}

\end{table}

\begin{verbatim}
