CHƯƠNG 3

Đây là chương thiết kế nên gần như mỗi mục đều nên có ít nhất một sơ đồ.

3.1: Ảnh website HUST + sơ đồ quy trình tra cứu hiện tại.
3.2: Bảng yêu cầu chức năng và phi chức năng + sơ đồ phân rã chức năng.
3.3: Use Case Diagram, Activity Diagram và Sequence Diagram.
3.4: Sơ đồ kiến trúc tổng thể (nên chiếm gần một trang) và sơ đồ chi tiết pipeline RAG.
3.5: ER Diagram, cấu trúc Document, Metadata và Collection.
3.6: Flowchart của Crawler.
3.7: Cấu trúc Chroma Database và Index.
3.8: Pipeline Retrieval → Prompt → Generation.
3.9: Cấu trúc Prompt (System, Context, User, Output).
3.10: Sơ đồ REST API và bảng Endpoint.
3.11: Wireframe giao diện Chat, Sidebar, History.
CHƯƠNG 4

Đây là chương có thể bổ sung nhiều ảnh chụp thực tế nhất.

4.1: Logo Python, LangChain, Chroma, FastAPI, React/Streamlit, Docker.
4.2: Ảnh VS Code/PyCharm, cấu hình máy, môi trường Docker.
4.3: HTML gốc → dữ liệu sau Parse → file JSON đã lưu.
4.4: Dữ liệu trước và sau khi làm sạch, ví dụ Chunking, bảng thống kê số chunk.
4.5: Minh họa vector embedding, biểu đồ phân bố vector.
4.6: Cấu trúc Collection trong Chroma, thư mục lưu trữ.
4.7: Ảnh kết quả Similarity Search với Top-k và MMR.
4.8: Prompt Template đầy đủ và sơ đồ luồng Prompt.
4.9: Ảnh gọi API đến LLM và ví dụ phản hồi.
4.10: Swagger UI của tất cả endpoint (Crawl, Search, Chat...).
4.11: Ảnh giao diện Chat, Sidebar, Lịch sử, Hiển thị nguồn dữ liệu.
4.12: Sơ đồ quy trình hoạt động hoàn chỉnh từ người dùng đến câu trả lời.
CHƯƠNG 5

Nên tập trung vào biểu đồ và kết quả thực nghiệm.

5.1: Bảng cấu hình máy và sơ đồ môi trường thực nghiệm.
5.2: Biểu đồ số lượng học phần, số trang đã crawl, số chunk.
5.3: Biểu đồ thời gian crawl, tỷ lệ lỗi, tỷ lệ thu thập thành công.
5.4: Biểu đồ so sánh BGE, E5 và OpenAI theo tốc độ và chất lượng.
5.5: Biểu đồ Recall@k, Precision@k, Hit Rate, MRR.
5.6: 8–10 ảnh chụp chatbot trả lời các câu hỏi khác nhau.
5.7: Bảng và biểu đồ so sánh LLM không dùng RAG với LLM có RAG.
5.8: Biểu đồ khảo sát Likert (cột, radar hoặc tròn).
5.9: Bảng tổng hợp ưu điểm, hạn chế và hướng cải thiện.
Nếu mục tiêu là đồ án khoảng 130–150 trang

Ngoài hình ảnh, bạn nên bổ sung thêm:

20–30 bảng (so sánh, thống kê, đánh giá).
15–20 sơ đồ (Use Case, Activity, Sequence, Pipeline, Flowchart, ERD...).
20–30 ảnh chụp màn hình (website, API, chatbot, cơ sở dữ liệu, giao diện).
15–20 biểu đồ (Bar Chart, Line Chart, Radar Chart, Pie Chart).

Nếu làm theo cách này, gần như mỗi mục lớn (2.1, 2.2, 3.4, 4.3, 5.5...) đều có ít nhất một hình hoặc bảng, giúp đồ án vừa tăng độ dài vừa có tính trực quan và chuyên nghiệp hơn.
